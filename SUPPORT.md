# Support

- **Questions and ideas**: [GitHub Discussions](https://github.com/enterprise-agent-skills/enterprise-agent-skills/discussions).
- **A skill gives wrong guidance**: open an issue with the **Skill problem** template. Include
  the prompt, the agent and model, what the agent did, and what the correct behavior is with a
  link to official documentation. Issues are public, so leave out customer data, credentials,
  host names, system IDs, and proprietary code.
- **Security problems**: follow [SECURITY.md](SECURITY.md). Do not open a public issue.
- **Conduct problems**: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

This is a community project without a support agreement. For problems with a vendor product
itself, contact the vendor's support channel.
