# Incubator

This folder holds no skills. Legacy drafts from earlier work are not part of this repository.
Before any of that material is published, it is migrated into a focused skill with acceptance
criteria, scenarios, and negative controls, and it passes the same review and checks as every
other skill. None of it appears in the catalog, the marketplaces, the install commands, or the
release packages until it has been migrated.

So far, `sap-abap-standard` and `sap-rap-business-object` in the `sap-abap` plugin were
rewritten from one of these drafts; both record it in `metadata.derived-from`. The SAP topics
planned next are listed in [docs/ROADMAP.md](../docs/ROADMAP.md).

To propose a skill, including one based on earlier work of your own, open a **Skill proposal**
issue as described in [CONTRIBUTING.md](../CONTRIBUTING.md).
